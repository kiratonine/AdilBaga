3. **`scrapeDana`** с тремя режимами:
   - `roots` — обход корня (fallback), теперь пулом;
   - `sections` — только подразделы из scope-файла; подраздел, исчезнувший из меню сайта, считается ошибкой;
   - `full` — все корни плюс аннотация подразделов (`rawPayload.sections`) для еженедельного прогона.
   Порядок товаров детерминирован, дубли отбрасываются, `sourceProductId` и `sourceCategoryPath` не изменились.
4. **`dana-scope`** и команда `pnpm scope:dana`: жадное покрытие подразделами, выход с кодом 1 при `unsectioned > 0`. Файл `data/mapping/dana-scope-sections.json` закоммитен (13 подразделов, покрытие 1184/1184).
5. **Подключение:** ветка `DANA` в `scrape.ts`, Dana в режиме `sections` отнесена к «хрупким» скрапам (ошибка → файл не пишется, exit 3 в daily-sync), еженедельный скрипт строит кандидат `dana-scope-sections.candidate.json`.
