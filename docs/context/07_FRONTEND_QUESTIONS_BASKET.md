# Adil Bağa — вопросы Frontend → Backend 1: продуктовая корзина на дашборде

На странице «Аналитика» хотим показать, **сколько стоит одна и та же продуктовая корзина в каждой сети**, и вывести эту сумму на карте у каждой точки сети (у всех точек Dana — сумма корзины Dana).

Одинаковых товаров во всех трёх сетях в датасете почти нет, поэтому корзина собирается **по категориям**: в каждой категории корзины берём самый дешёвый подходящий товар сети и суммируем.

Считать предлагаем на бэке: состав корзины живёт в одном месте, фронт только показывает. Фронт делаем сразу на моках по формату ниже. Если формат подходит, достаточно ответить «ок». Если нет, поправьте прямо в файле.

Всё ниже — **предложения**, текущий контракт они не меняют: поле additive, пока его нет, фронт блок корзины просто не показывает.

---

## 1. Новое поле `baskets` в `GET /api/dashboard`

```ts
type DashboardDto = {
  summary: { ... }                  // без изменений
  priceSpreads: PriceSpreadDto[]    // без изменений
  locations: StoreLocationDto[]     // без изменений
  baskets?: BasketDto[]             // новое, по одной корзине на сеть
}

type BasketDto = {
  storeCode: StoreCode              // тот же код, что в locations[].storeCode
  storeName: string
  total: number                     // сумма найденных позиций, ₸
  items: BasketItemDto[]            // все позиции корзины, в одном порядке у всех сетей
}

type BasketItemDto = {
  categorySlug: string
  categoryName: string              // «Молоко»
  productId: string | null          // null — в этой сети нет подходящего товара
  name: string | null
  price: number | null
}
```

Пример:

```json
{
  "baskets": [
    {
      "storeCode": "DINA",
      "storeName": "Dina Market",
      "total": 3120,
      "items": [
        { "categorySlug": "milk", "categoryName": "Молоко", "productId": "c1", "name": "Молоко FoodMaster 3,2% 1 л", "price": 570 },
        { "categorySlug": "eggs", "categoryName": "Яйца", "productId": null, "name": null, "price": null }
      ]
    }
  ]
}
```

**Вопрос:** формат подходит?

## 2. Состав корзины

Предложение — 6 позиций из категорий, которые уже есть в датасете:

| Категория | Условие (если по данным получится) |
|---|---|
| `milk` — молоко | 1 л |
| `bread` — хлеб | любой |
| `sugar` — сахар | 1 кг |
| `oil` — масло | 1 л |
| `eggs` — яйца | 10 шт |
| `tea` — чай | любой |

**Вопросы:**
- Подходит такой состав? Может, добавить или убрать что-то.
- Получится ли выдержать условия по объёму/весу/количеству из атрибутов товара? Если нет, берите самый дешёвый товар категории, но тогда напишите нам об этом: корзины станут менее сравнимы, и на фронте мы добавим оговорку.

---

## 3. Правила подсчёта

Предложение:
- в каждой позиции — самый дешёвый подходящий товар **этой сети** (по её offer'ам);
- товары не в наличии (`inStock: false`) не учитываем, если поле есть;
- если в сети нет подходящего товара, позиция приходит с `productId/name/price = null`, а `total` — сумма только найденных позиций. Фронт такую корзину пометит «Нет N из 6 позиций» и не будет считать её самой выгодной;
- порядок `baskets` не важен, фронт сортирует сам.

**Вопрос:** согласны с этими правилами?
