# Дизайн-код D4b: товар, поиск, аналитика, состояния — план внедрения

**Goal:** Довести оставшиеся страницы до дизайн-кода: товар (белые карточки, точки сетей, бейджи, «Показать все N»), поиск, «Аналитика» (блоки в белых карточках), состояния и 404; закрыть хвосты из ревью D1–D3.

**Spec:** `docs/superpowers/specs/2026-10-02-design-system-design.md` §6 (Товар, Поиск, Аналитика), §7, §9.

Рабочая папка — `frontend-next/`. Лендинга нет (D4a). После D4b — «Next 5. e2e и переключение».

## Решения в рамках D4b

- **Состояния (`States.tsx`):** `ErrorState` и `EmptyState` — белая карточка (`bg-card rounded-card`) по центру: иконка 32px `muted` (`alert` у ошибки; у пустого — проп `icon`, по умолчанию `search`), текст, действие. «Повторить» — `Button secondary`. Testid прежние. Пустая категория с фильтрами — иконка `sliders`.
- **404 (`NotFoundPage`):** та же карточка состояния с `h1`, ссылка в каталог — `Button primary href` (вместо зелёной ссылки: зелёный — только выгода). Пустой поиск — ссылка в каталог тоже `Button secondary`.
- **Товар:**
  - Фото — в белой карточке (`bg-card rounded-card p-3`, фото `rounded-media`), sticky на ≥ md. Плейсхолдер — иконка категории (`categoryIcon(slug)`, `muted`) вместо ценника: проп `icon` у `ProductImage`; без него — прежний ценник (карточка в сетке).
  - Правая колонка: бренд, h1 (`text-h1`), подпись «Самая низкая цена»/«Цена», `text-price-page` + `Badge discount` (−X%, `discountPercent` лучшего предложения) + старая цена, `SavingLine`. **На мобильном цена выше h1** (спека: «фото, далее цена, h1») — через `order`, в DOM h1 остаётся первым.
  - «Цены в магазинах» (текст ключа `card.offers` не меняем) — белая карточка; строка: точка цвета сети (`storeColor`) · название + подпись · цена `text-price-row` (+ старая). Лучшая — `bg-accent-soft`, `Badge best` «Дешевле всего»; остальные — «дороже на X ₸» `meta muted`; одно предложение — `Badge neutral` «Только в этой сети». Видны первые 5 (`OFFERS_VISIBLE = 5`); больше — `Button ghost` «Показать все N» (`show-all-offers`, ключ `product.showAll`), раскрывает остальные и исчезает. Дата снимка — внизу карточки.
  - Характеристики — белая карточка, `dl`: строки на мобильном, 2 колонки пар с md.
- **Поиск:** подсказка «Что ищем?» и «ничего не нашлось» — через новые `EmptyState`; заголовок `text-h1`.
- **Аналитика:** h1 `text-h1`, заголовки секций `text-h2`, между секциями 32/48px. Плитки сводки — `bg-card`. Корзины — `bg-card` (лучшая — `accent-soft`). Карта и список точек — одна белая карточка (карта `rounded-card overflow-hidden`). Разброс цен — список в белой карточке. Логика и порядок не меняются.
- **Хвосты:** все `rounded-[var(--radius-*)]` → `rounded-card`/`rounded-control`; `ProductImage` проверяет `img.complete && naturalWidth === 0` при монтировании (картинка упала до гидрации → плейсхолдер вместо alt); `Chip` — стили `disabled`; скелетоны товара и «Аналитики» под новую геометрию.

## Задачи

1. `States.tsx` (карточка, иконка, `secondary`), `NotFoundPage`, пустые состояния поиска/категории + тесты (иконка, «Повторить» — secondary, 404 — ссылка в каталог).
2. `ProductImage`: проп `icon`, проверка упавшей до гидрации картинки + тест.
3. `ProductPage`: раскладка, бейджи, точки сетей, «Показать все N» (тест на товаре с 7 предложениями — подмена `getProduct` в моке), характеристики карточкой; `ProductPageSkeleton`; i18n `product.showAll` ru/kk.
4. `DashboardPage` + `Baskets` + `StoreMap`: белые карточки, шкала шрифтов; `DashboardSkeleton`.
5. `SearchPage`: `text-h1`, пустые состояния. `Chip` disabled, оставшиеся `rounded-[var(...)]`.
6. Проверка: typecheck, `rtk proxy pnpm lint`, unit, `next build`, e2e (`PW_CHANNEL=chrome`), скриншоты 390/1280 товара, поиска, «Аналитики», 404; worklog.

## Review focus

- Товар с одним предложением: нет зелёного, нет «Дешевле всего», бейдж «Только в этой сети».
- Несколько предложений с одинаковой минимальной ценой — обе строки «Дешевле всего» (как раньше, `price === minPrice`).
- Ровно 5 предложений — кнопки «Показать все» нет; 6+ — есть, после клика все видны.
- Длинное название капсом на 320px — h1 переносится (`break-words`), без горизонтального скролла.
- Ошибка внутри уже загруженной страницы (`(site)/error.tsx`) — та же карточка с «Повторить».
