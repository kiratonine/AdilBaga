# Adil Bağa — дизайн-код (desktop + mobile)

Дата: 2026-10-02 · Статус: согласовано в брейншторме, ждёт ревью спеки
Мокапы (открыть в браузере): [card.html](2026-10-02-design-system/card.html) — карточка товара (выбран вариант A), [catalog.html](2026-10-02-design-system/catalog.html) — витрина каталога и мобильная оболочка (выбран вариант A плиток).

## 1. Цель и рамки

Привести сайт к паттернам лучших маркетплейсов, сохранив свою идентичность (направление «эволюция»): минимализм, зелёный — только «здесь выгоднее», логотип-ценник со знаком «=». Касается всех страниц и мобильной версии.

Сохраняется без изменений: тексты (лендинг пользователь правит сам), логика данных, роутинг, SEO, i18n, все существующие testid, порядок блоков «Аналитики».

### Что показал ресёрч (2026-10-02, инспекция computed styles)

Изучены Kaspi, Ozon, Wildberries, Яндекс Маркет, Uzum, Arbuz, Instacart, idealo (Amazon и Самокат отдали бот-заглушку).

- **Шрифт:** у всех один гротеск на весь UI (Ozon Sans, YS Text, Instacart Sans, Inter/Roboto). Базовый размер 14px, подписи 12–13px. Цена — тот же шрифт, 16–20px, 700.
- **Карточка:** цена первой, над названием (Ozon, WB, Яндекс); порядок фото → цена → старая цена/−% → бренд → название в 2 строки. Без рамки, скругление 12px (WB 16px).
- **Цвет:** серый фон страницы (`#F5F7FA` Ozon, `#F6F6F9` WB, `#F5F3F1` Яндекс) + белые блоки; один цвет бренда для действий и отдельный — для выгоды.
- **Формы:** чипы и «таблетки» — 100px; кнопки и поля — 8–12px.
- **Мобильный:** сетка 2 колонки с отступом 8px, sticky-поиск, нижний таб-бар, фильтры шторкой, горизонтальные полки.

Отступления от рынка — сознательные: оставляем Montserrat для цен (узнаваемость, выбор пользователя в сессии 6); базовый размер 15px, а не 14px (продуктовые названия длинные, аудитория широкая); основная кнопка — `ink`, а не цвет бренда (зелёный занят смыслом «выгоднее»).

## 4. Карточка товара (вариант A)

Файл: `components/product/ProductCard.tsx`. Вертикальная на всех ширинах (горизонтальная мобильная версия уходит).

Порядок сверху вниз:
1. Фото — квадрат `aspect-square`, `surface`, `radius-media`; при отсутствии фото — иконка категории (иначе нейтральная). Бейдж `discount` «−X%» в левом верхнем углу, если у лучшего предложения `oldPrice > price` (процент округляется вниз).
2. Цена `price-card` (`min-price`) + старая цена зачёркнутая (`meta`, `muted`).
3. `SavingLine` (фраза `ink`, сумма `accent` 600) — как сейчас.
4. Бренд (`meta`, `muted`), если есть.
5. Название `card-title`, 2 строки; растянутая ссылка на всю карточку — как сейчас.
6. Список сетей (`offer-list`): **топ-3 по цене**. Лучшее — `accent-soft`/`accent`/500 (`li[data-best]`), если предложений больше одного.
7. Если предложений > 3 — строка `more-offers` (`meta`, `muted`): «ещё N сетей · до X ₸» (X — максимальная цена). Отдельной ссылкой не делаем — карточка уже ссылка.
8. Дата снимка (`snapshot-date`, caption) прижата к низу (`mt-auto`) — карточки в ряду одной высоты.

Стиль: `card` фон, без рамки, `radius-card`, отступ 8/12px, `shadow-hover` на hover.

Логика: `lib/offers.ts` — новая чистая функция `topOffers(offers, limit)` → `{ shown, hiddenCount, maxPrice }` (на основе существующей `sortOffers`). Правило «одно предложение — без зелёного и без “Дешевле всего”» сохраняется.

`ProductGrid`: `grid-cols-2` / `md:grid-cols-3` / `lg:grid-cols-4`, отступ 8/16px. Проп `wide` больше не нужен — убрать, если других отличий не останется.

### Компактная карточка для полки

`ProductCard` с пропом `variant="compact"`: ширина 150px (мобильный) / 200px (≥ md), без списка сетей и даты; фото, цена, строка выгоды (без названия сети: «Выгоднее на X ₸»), название. Тот же `product-card` testid.

### Полка — `components/product/Shelf.tsx`

Заголовок h2 + горизонтальный ряд компактных карточек: `overflow-x-auto`, `scroll-snap-type: x mandatory`, скрытый скроллбар, выход за правый край контейнера на мобильном (подсказка «листай»). ≥ md — кнопки ‹ › (`ghost`, круглые) прокручивают на ширину видимой области; скрыты, если прокручивать некуда. Testid `shelf`.

## 5. Оболочка

### Шапка — `components/layout/Header.tsx`

- Фон `card`, sticky, нижняя граница `line` (без blur).
- ≥ md: лого · поиск (до 560px) · «Каталог», «Аналитика» — текстовые ссылки Golos 500, активная — `ink` с подчёркиванием 2px снизу (без зелёной плашки) · `Segmented` RU/KZ.
- Мобильный: строка 1 — лого + `Segmented`; строка 2 — поиск на всю ширину. Навигационные ссылки скрыты (они в таб-баре). Testid `nav-catalog`/`nav-dashboard` остаются на ссылках шапки (видны на ≥ md); у таб-бара свои testid (`tab-catalog`, `tab-search`, `tab-dashboard`), e2e проекта iphone переходят на них.
- Поле поиска: высота 44px, фон `surface`, без рамки, иконка лупы слева, `radius-control`; фокус — `outline` по `:focus-visible` (как сейчас, цвет `ink`, см. ниже).

### Таб-бар — `components/layout/TabBar.tsx` (новый)

- Только `< md`, в layout группы `(site)` и в `not-found`. На лендинге нет.
- `<nav aria-label={t('nav.main')}>`, testid `tab-bar`, фиксирован снизу, фон `card`, верхняя граница `line`, `padding-bottom: env(safe-area-inset-bottom)`.
- 3 пункта: Каталог (`/catalog`) · Поиск (`/search`) · Аналитика (`/dashboard`); иконка 24px + подпись 11px; активный — `ink` 600 + `aria-current="page"`, остальные `muted`. Каталог активен и на `/collections/*` и `/products/*`.
- Таб «Поиск» — ссылка на `/search`. `SearchBox` фокусирует своё поле, когда пользователь пришёл на `/search` с пустым `q` клиентской навигацией (при первой загрузке страницы фокус не ставим — не открывать клавиатуру без действия пользователя). Флагов в URL не добавляем.
- `Main` получает нижний отступ `calc(64px + env(safe-area-inset-bottom))` на `< md`, чтобы таб-бар не перекрывал контент и футер.

### Фокус

`:focus-visible` — outline 2px `ink` (было `accent`: зелёный оставляем только для выгоды), offset 2px.

## 9. Тестирование

- Все существующие testid сохраняются. Новые: `tab-bar`, `tab-catalog`, `tab-search`, `tab-dashboard`, `filters-sheet`, `shelf`, `more-offers`, `show-all-offers`.
- Unit (Vitest + Testing Library):
  - `lib/offers.ts` `topOffers`: ≤ 3 предложения, > 3 (hiddenCount, maxPrice), одно предложение.
  - `lib/categoryIcons.ts`: известный слаг → своя иконка, неизвестный → запасная.
  - `ProductCard`: топ-3, строка `more-offers`, бейдж «−X%», отсутствие зелёного при одном предложении.
  - `TabBar`: активный пункт и `aria-current` для `/catalog`, `/collections/x`, `/products/x`, `/search`, `/dashboard`.

- E2E (Playwright, проекты `desktop` и `iphone`): на iphone виден таб-бар и навигация через него; фильтры открываются шторкой; на desktop таб-бара нет. Существующие сценарии обновить под новые элементы управления на мобильном.
- Визуальная проверка после каждого этапа: скриншоты 390 и 1280 против мокапов.
- `pnpm typecheck && pnpm lint && pnpm test` зелёные на каждом этапе.
