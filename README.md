# Adil Bağa (Әділ баға) — «Справедливая цена»

Сервис мониторинга и сравнения цен на социально значимые и повседневные продукты питания в городе **Актау** (Мангистауская область, Казахстан). Проект разрабатывается в рамках хакатона **Smart City Aktau**.

---

## 🎯 Миссия и задачи проекта

Жителю Актау приходится самостоятельно искать товары на сайтах различных сетей, чтобы узнать, где нужный продукт дешевле. **Adil Bağa** агрегирует данные из ключевых торговых сетей города (**Dina Market**, **Dana Market**, **Fix Price**), нормализует параметры товаров и предоставляет:
1. Каталог товаров с прозрачным сравнением цен между сетями.
2. Информацию о максимальной выгоде (разброс цен достигает **до 53%** на идентичные SKU).
3. Карту с точными координатами филиалов магазинов в микрорайонах города Актау.
4. Голосовой поиск и сценарии для голосовых ассистентов (Siri Shortcut).

---

## 🏗 Архитектура проекта и стримы

Проект разделен на три параллельных стрима:
- `feat/frontend`: Веб-интерфейс (React, каталог, фильтры, карточка товара, аналитический дашборд, карта).
- `feat/backend-1`: Прикладной бэкенд (NestJS HTTP API, voice endpoint, геодистанция, сессии).
- **`feat/backend-2` (текущая ветка)**: Слой данных (**Data Layer**), схема PostgreSQL/Prisma, парсеры каталогов розничных сетей, детерминированная нормализация, алгоритмы сопоставления (Product Matching), сидирование точек Актау и формирование воспроизводимого снапшота.

Подробная документация слоя данных находится в [**`backend/README.md`**](backend/README.md).

## 📊 Метрики датасета Актау

- **Сырых товаров (Raw Products):** 243
  - Dina Market (Гипермаркет 301, 33 мкр): 144
  - Dana Market: 79
  - Fix Price: 20
- **Канонических товаров (Canonical Products):** 121
- **Филиалов магазинов в Актау:** 12 локаций
- **Примеры ценового разброса:**
  - *Nemoloko Овсяное 3.2% 1 л*: 650 ₸ (Fix Price) vs 995 ₸ (Dana) — **разница +53% (345 ₸)**
  - *Масло Слобода 1 л*: 890 ₸ (Fix Price) vs 1008 ₸ (Dana) — **разница +13% (118 ₸)**

## 🚀 Быстрый старт (Backend 2)

```bash
cd backend

# 1. Установка зависимостей
npm install

# 2. Настройка переменных окружения
cp .env.example .env

# 3. Инициализация Prisma и генерация клиента
npm run db:generate
npm run db:migrate

# 4. Запуск сквозного пайплайна сбора и сопоставления
npm run data:pipeline

# 5. Запуск аудита и стресс-тестов (38 проверок)
npm run test:audit

# 6. Отчёт о качестве данных
npm run data:report

# 7. Наполнение базы данных снапшотом
npm run db:seed
```
